# RegExp

Регулярные выражения (RegEx или regexp) — это формальный язык и мощный механизм для поиска, валидации и манипуляции текстом на основе заданного шаблона (pattern)

Обозначается с помощью 2 наклонных черт ``/regexp/flags``

# Какие методы используются в регулярных выражениях?

## test(string)

- возвращает true если переданная строка соответствует выражению
```js
/[a-z]/.test('something') // true
/[a-z]/.test('123') // false
```
## exec(string)

- возвращает массив с совпадением, а также содержит свойство index c которого начинается совпадение
```js
const string = 'I know 5 languages, 2 of them are the official languages of Belarus'
/[/d]+/.exec(string) // ['5', index: 7, length: 1 ]
```

# Основные знаки

. - любой символ
^ - начало строки
$ - конец строки

* - 0 и более повторений
+ - 1 и более повторений
? - 0 или 1 повторение

() - логическая группа
[] - группа символов
[^] - символы кроме перечисленных в скобках
{1} {0,} {1, 6} - количество вхождений

\d - цифры, эквивалентно [0-9]
\D - не цифра, [^0-9]
\w - буква латинского алфавита, цифра или нижнее подчеркивание [A-Za-z0-9_]
\W - все кроме буква латинского алфавита, цифра или нижнее подчеркивание [:A-Za-z0-9_]
\s - пробел
\S - все кроме пробела

Флаги
g - ищет все совпадения
i - поиск не зависит от регистра
m - многострочный режим
