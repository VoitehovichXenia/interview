# Переменные

Объявляются с помощью ключевых слов:
- **var**
- **let**
- **const**

Ограничения имен переменных:
- могут состоять из цифр, букв и символов $ и _
- первый символ НЕ может быть цифрой
- нельзя использовать зарезервированные имена (new, function и т.д.)
- регистр имеет значение
- naming conventions: snake_case, camelCase

## Отличия var, let и const

Let:
- обладает блочной областью видимости (function, while, if, for или все что ограничено {...}); var — функциональная (доступен внутри всей функции или глобально).
- доступна только после обявления (не подвержена hoisting)
```ts
console.log(a) // undefined, т.к переменная объявлена но не инициализирована
var a = 5;

console.log(b) // ReferenceError
let b = 5;
```
- let нельзя объявить повторно в той же области видимости. var позволяет переобъявлять переменные без ошибок
- при использовании в цикле для каждой итерации создается своя переменная
- Переменные var (объявленные глобально) становятся свойствами объекта window, а let — нет.
