# Циклы

**Цикл** - конструкция выполняющая действие или набор действий, пока заданное в нем условие выполняется

**Итерация** - один проход цикла

Виды циклов:

- **while**
    ```ts
    while (/* condition */) {
      /* body */
    }
    ```

- **do while**
    Выполнится всегда хотя бы 1 раз

    ```ts
    do {
      /* body */
    } while (/* condition */)
    ```

- **for**
    ```ts
    for (let i = 0; i < 10; i++) {}

    // for...in для перебора итерируемых сущностей
    for (let key in object) {}

    // for...of для перебора итерируемых сущностей
    for (let fruit of fruits) {
      alert( fruit );
    }
    ```

    Отличия 
    - цикл **for..in** выполняет перебор всех свойств объекта (даже внутренних)
    - цикл **for..in** оптимизирован под произвольные объекты, не массивы, и поэтому в 10-100 раз медленнее. 
    - цикл **for..of** оптимизирован под массивы и псевдомассивы

Для всех циклов существуют специальные ключевые слова:

- **break** - выход из цикла
- **continue** - переход к следующей итерации
- **<name>:** - метка цикла для вложенных циклов, может использоваться для break и continue
    ```ts
    outer:for (let i = 0; i < 3; i++) {
      for (let k = 0; k < 10; k++) {
        if ((i + k) % 2) break outer;
      }
    }
