# Что такое Set?

Set (множество) — это структура данных или коллекция, хранящая только уникальные элементы (дубликаты автоматически игнорируются)

# Основные методы Set

## add(value)

- добавляет значение в коллекцию [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/add)

## clear()

- очищает колекцию [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/clear)

## delete(value)

- удаляет значение из коллекции [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/delete)

## difference(Set)

- возвращает новый Set значениями которого будут те значения которые не входят в переданный Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/difference)

## entries()

- возвращает итератор с парами ``[value, value]`` [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/entries)

## forEach(callback(value, value, set))

- выполняет callback для каждого значения [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/forEach)

## has(value)

- возвращает true если значение есть в Set, иначе false [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/has)

## intersection(Set)

- возвращает новый Set значениями которого будут те значения которые входят в оба Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/intersection)

## isDisjointFrom(Set)

- возвращает true если имеются общие значения [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/isDisjointFrom)

## isSubsetOf(Set)

- возвращает true если есть все значения из переданного Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/isSubsetOf)

## isSupersetOf()

- возвращает true если все значения есть в переданном Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/isSupersetOf)

## keys()

- возвращает итератор со всеми занчениями Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/keys)

## symmetricDifference(Set)

- возвращает новый Set значениями которого будут те значения которых нет в переданном Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/symmetricDifference)

## union(Set)

- возвращает новый Set который является результатом объединения с переданным Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/union)

## values()

- возвращает итератор со всеми занчениями Set [Читать дальше](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/values)
