# XSS аттака

**XSS** (Cross-Site Scripting, межсайтовый скриптинг) — это тип уязвимости веб-приложений, позволяющий злоумышленнику внедрить вредоносный JavaScript-код на страницу, просматриваемую другими пользователями.

Этот код выполняется в браузере жертвы, позволяя красть сессионные куки (cookies), подменять контент, перенаправлять пользователей или совершать действия от их имени.

Основные типы XSS-атак
1. Хранимый (Stored/Persistent) XSS: Самый опасный тип. Вредоносный скрипт навсегда сохраняется на сервере (например, в базе данных комментариев, профилях пользователей) и отправляется каждому, кто открывает страницу.
2. Отраженный (Reflected) XSS: Скрипт не хранится на сервере, а передается в запросе (обычно через параметры URL). Пользователь переходит по специально сформированной ссылке, и сервер «отражает» вредоносный код обратно в браузер.
3. DOM-based XSS: Атака происходит полностью на стороне клиента. Вредоносный код изменяет DOM-окружение (Document Object Model) в браузере жертвы, не взаимодействуя напрямую с сервером. 

Последствия XSS-атак
- Кража сессий
- Фишинг: Подмена содержимого страницы (например, формы входа) для кражи паролей.
- Распространение вредоносного ПО: Автоматическое перенаправление на сайты с вирусами.
- Действия от имени пользователя: Отправка сообщений, удаление данных, изменение настроек. 

# CSRF аттака

**Cross-Site Request Forgery** (CSRF,  «межсайтовая подделка запроса») -  это атака, заставляющая авторизованного пользователя выполнить нежелательные действия на доверенном сайте (например, сменить пароль или перевести деньги) через скрытую отправку запроса с другого сайта. Уязвимость возникает, так как браузеры автоматически прикрепляют куки (cookie) сессии к запросам.

Как аттака работает:
1. Юзер проходит аутентификацию на доверенном сайте => получает аутентификационные куки
2. Юзер заходит на вредоносный сайт
3. Вредоносный сайт посылает запрос на сервер доверенного сайт (например, (e.g., bank.com/transfer?amount=1000&to=attacker))
4. Браузер автоматически прикрипляет session cookies, и доверенный сайт исполняет вредоносное действие

# Clickjacking

**Clickjacking** - это вид кибератаки, при которой злоумышленники скрывают вредоносные элементы интерфейса (кнопки, ссылки) под прозрачным слоем поверх легитимного сайта. Пользователь думает, что нажимает на безобидную кнопку (например, «Играть»), а на самом деле выполняет скрытое действие: переводит деньги, удаляет данные или подписывается на сервисы
