# Что такое HTML

**HTML** - hypertext markup language (язык гипертекстовой разметки)

 - hypertext - ссылки, которые соединяют веб-страницы друг с другом либо в пределах одного веб-сайта, либо между веб-сайтами

- markup - разметка, которая включает в себя специальные "элементы" (тэги) для отображения контента

# Для чего используется HTML

HTML используется для создания структуры и каркаса веб-страниц и ее интерпретации браузером, определяя содержание страницы, т.е. что именно будет изображено.

# Что такое HTML элемент и из чего он состоит

**HTML-элемент** - это базовый компонент веб-страницы, определяющий структуру и содержимое контента (текст, изображения, ссылки) для браузера.

Элемент состоит из:
- открывающего и закрывающего тега
- содержимого

# Что такое HTML аттрибут

**HTML-атрибуты** — это модификаторы внутри начального тега, определяющие поведение, стиль или свойства элемента. 

Состоят из **имени** и **значения** (имя="значение"), пишутся строчными буквами и используются для настройки отображения, ссылок, форм и передачи данных. 

Основные типы атрибутов

По scope действия:
- **Глобальные атрибуты** (можно использовать с любым HTML-элементом)
- **Специфичные атрибуты** (относятся только к определенным тегам)
  Пример: href (<a>), src (<img>)

По выполняемой роли:
- **Атрибуты событий** (используются для запуска JS при взаимодействии с пользователем)
  Пример: onclick, onmouseover.
- **Пользовательские данные** (data-\*): Атрибуты вида data-\* позволяют хранить дополнительную информацию в DOM-элементе. 

# Глобальные аттрибуты

- **accesskey** (добавляет подсказку о том, какое клавиатурное сокращение поддерживает элемент; список клавиш, разделённых пробелом)
- **autofocus** (определяет должен ли элемент быть сыокусирован при загрузке страницы или при открытии диалогового окна через <dialog> or popover)
- **class** (задает 1 или несколько классов)
- **contenteditable** (boolean; делает любой элемент редактируемым)
- **data-\*** (пользовательские данные)
- **dir** (направление письма; ltr — слева направо, rtl — справа налево и auto — определяется браузером)
- **draggable** (элемент можно перетаскивать)
- **enterkeyhint** (определяет, какой клавишей на устройствах с экранной клавиатурой можно совершить действие с элементом; enter, done, go, next, previous, search или send)
- **exportparts** (позволяет стилизовать компоненты с помощью ::part() распологающиеся внутри shadow trees; имена частей)
- **hidden** (скрывает элемент со страницы не только для пользователя, но и для скринридеров)
- **id** (уникальный иднгтификатор)
- **inert** (делает элементы неактивными, а ещё скрывает их от скринридеров)
- **is** (позволяет указать, что стандартный HTML-элемент должен вести себя как определенный встроенный элемент).
- **itemscope** (cвязывает несколько элементов в один, когда они содержат данные в виде пары ключ-значение)
- **itemprop** (содержит уникальные значения элементов из группы, связанной в один элемент через itemscope; строка)
- **itemtype** (тип структуры данных у элементов внутри группы itemscope; ссылка на нужную таблицу на Schema.org)
- **itemid** (добавляет к элементу внутри itemscope уникальный идентификатор; Значение: уникальный URL, связанный со Schema.org)
- **itemref** (добавляет к элементу внутри itemscope уникальный идентификатор; одно или несколько ID, которые разделены пробелом)
- **lang** (определяет, язык текста внутри элемента)
- **nonce** (определяет криптографический nonce ("number used once"), который может использоваться Content Security Policy для определения того, будет ли  разрешено продолжение получения данных для данного элемента)
- **part** (содержит список имен частей элемента, разделенных пробелами)
- **popover** (используется для обозначения элемента как элемента всплывающего окна)
- **role** (указывает явную роль; любая ARIA-роль)
- **slot** (назнаачает элементу slot в shadow DOM shadow tree)
- **spellcheck** (проверка правописания)
- **style** (inline стили)
- **tabindex** (указывает браузеру, нужно ли видеть этот элемент при навигации по странице с помощью клавиатуры; < 0 — элемент может быть выделен, но не участвует в последовательной цепочке навигации. 0 — элемент включается в цепочку последовательной навигации, но порядок остаётся на усмотрение браузера. Положительное число — элемент участвует в последовательной навигации, причём чем больше указанное значение, тем выше элемент будет в цепочке навигации. Если у нескольких элементов одинаковые значения, то они идут по порядку следования в HTML)
- **title** (подсказка)
- **translate** (указывает на возможность перевести текст элементаж; yes — текст может быть переведён, no — не переводить содержимое тега)
